Фінальний проект з розробки AI-додатків та використання React Native.

Розроблений додаток створений для вичення англійської мови. 
Користувач може обрати одну з трьох тем: Wealth and Social Class, Financial Systems або War and Conquest. 
Кожна тема містить перелік слів для вивчення та текст для практики цих слів. 
Користувач може скористатися AI-помічником для перекладу наданого тексту та перевірки себе. Додаток має функцію пошуку по темам.
